About

Stardew Valley Mod Manager

A modern, pixel-art styled desktop application for managing Stardew Valley SMAPI mods. Built with Tauri for enhanced security and performance.

Open Source Tauri 2.8.4 Rust + TypeScript
🔗 GitHub Repository

Developer

merchizm

Technical Details

Frontend

  • TypeScript
  • Vite
  • CSS3 with Pixel Art Styling
  • HTML5

Backend

  • Rust
  • Tauri 2.8.4
  • Serde for JSON handling
  • Tokio for async operations

Key Features

  • Cross-platform support
  • Enhanced security model
  • Lower resource usage
  • Multi-language support
